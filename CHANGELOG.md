# Changelog

All notable changes are documented here.

## 1.3.0 - 2026-08-02

- Added original extension icons and store artwork.
- Added Firefox Manifest V3 metadata and a no-data-collection declaration.
- Changed preferences from synchronized storage to local-only storage.
- Added publication, privacy, security, and contribution documentation.
- Added repeatable package building and GitHub validation/release workflows.
- Kept a prominent warning that stream detection is still under testing.

## 1.2.0 - 2026-08-02

- Added filtering for archived livestream recordings.
- Added an independent setting for past livestreams.
- Added autoplay skipping for archived livestreams.

## 1.1.0 - 2026-07-30

- Updated live detection for YouTube's renderer data.
- Improved lazy-loaded card scanning and autoplay detection.

## 1.0.0 - 2026-07-30

- Initial testing release.
