# Privacy Policy

Effective date: August 2, 2026

No Live for YouTube does not collect, transmit, sell, or share personal data.

## Data handled locally

The extension reads YouTube page elements and player metadata solely to decide
whether a video is a live, upcoming, or archived livestream. This processing
happens locally inside the browser.

The extension stores only its on/off preferences using the browser's local
extension storage. These preferences are not sent to the developer and are not
used for analytics or advertising.

## Network activity

The extension does not operate a server and does not make its own network
requests. YouTube itself continues to make normal requests under YouTube's own
terms and privacy policy.

## Permissions

- `storage`: saves extension settings locally.
- `https://www.youtube.com/*`: allows the extension to identify and hide stream
  recommendations on YouTube pages.

## Changes and contact

Material changes will be documented in this repository. Questions and privacy
concerns can be submitted through the repository's GitHub Issues page:
https://github.com/dziorke/no-live-for-youtube/issues
