# Contributing

Thank you for helping test No Live for YouTube.

## Reporting a bug

Open a GitHub issue and include:

- browser name and version;
- operating system;
- YouTube display language;
- page type, such as Home, Search, Subscriptions, or Watch;
- whether the problem involved a visible card or autoplay;
- a screenshot with private information removed, if useful.

Do not post account cookies, authentication headers, private playlists, or
other sensitive information.

## Code changes

1. Create a focused branch.
2. Keep the extension single-purpose and dependency-free.
3. Run `node --check` on every JavaScript file.
4. Load the extension unpacked and test YouTube navigation and settings.
5. Explain the YouTube layout or metadata that motivated detection changes.
